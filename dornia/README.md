# گالری طلای درنیا

فروشگاه اینترنتی طلا با قیمت‌گذاری خودکار بر اساس نرخ لحظه‌ای، سبد خرید، ثبت و پیگیری سفارش و پنل مدیریت فارسی.

## امکانات

**بخش مشتری**
- نوار قیمت لحظه‌ای طلا و سکه بالای همه صفحات
- فروشگاه با دسته‌بندی، جستجو، فیلتر زنانه/مردانه و مرتب‌سازی بر اساس قیمت
- صفحه محصول با گالری عکس، انتخاب سایز (هر سایز وزن و قیمت خودش را دارد) و ریز قیمت (ارزش طلا، اجرت، سود، مالیات)
- سبد خرید و ثبت سفارش، پرداخت کارت به کارت با بارگذاری رسید یا هماهنگی تلفنی
- پیگیری سفارش با کد سفارش و شماره موبایل
- ماشین‌حساب قیمت طلا، دکمه واتس‌اپ و نسخه موبایل

**پنل مدیریت** (`/admin`)
- داشبورد: سفارش‌های امروز، فروش ۳۰ روز اخیر، محصولات ناموجود
- افزودن و ویرایش محصول با آپلود چند عکس و پیش‌نمایش زنده قیمت
- مدیریت سفارش‌ها: دیدن رسید، تغییر وضعیت، پیام برای مشتری (مثلاً کد رهگیری پست)، پیام واتس‌اپ با یک کلیک
- تنظیمات: قیمت طلا (خودکار یا دستی)، درصد سود و مالیات، شماره کارت، اطلاعات تماس، رمز عبور

## فرمول قیمت

```
ارزش طلا = وزن × نرخ هر گرم طلای ۱۸ عیار
اجرت     = ارزش طلا × درصد اجرت محصول
سود      = (ارزش طلا + اجرت) × درصد سود        (پیش‌فرض ۷٪)
مالیات   = (اجرت + سود) × درصد مالیات          (پیش‌فرض ۱۰٪)
قیمت نهایی = جمع موارد بالا، گرد شده به بالا (پیش‌فرض: هزار تومان)
```

## نصب روی هاست

نیازمندی‌ها: **PHP 8.1 یا بالاتر** با افزونه‌های `pdo_sqlite` و `curl`. تقریباً همه‌ی هاست‌های لینوکسی (cPanel یا DirectAdmin) این‌ها را دارند. نیازی به ساخت دیتابیس MySQL نیست.

1. همه‌ی محتویات این پوشه را در `public_html` هاست آپلود کنید.
2. پوشه‌های `data` و `uploads` باید قابل نوشتن باشند (معمولاً به‌طور پیش‌فرض هستند).
3. **بلافاصله** آدرس `yoursite.ir/admin` را باز کنید و رمز عبور مدیر را تعیین کنید.
4. در «تنظیمات و قیمت طلا»: اطلاعات تماس، شماره کارت و کلید سرویس قیمت را وارد کنید.
5. محصولات نمونه را با محصولات واقعی جایگزین کنید.

### اگر سرور Nginx است (VPS)
فایل‌های `.htaccess` فقط روی Apache/LiteSpeed کار می‌کنند. روی Nginx این تنظیم را به بلوک `server` اضافه کنید تا دیتابیس و رسیدها قابل دانلود نباشند:

```nginx
location ~ ^/(data|app)/ { deny all; }
location ~ ^/uploads/.*\.php$ { deny all; }
```

### قیمت خودکار طلا
در سایت [brsapi.ir](https://brsapi.ir) ثبت‌نام کنید، کلید رایگان بگیرید و در تنظیمات وارد کنید. بعد دکمه‌ی «ذخیره و تست دریافت قیمت» را بزنید.
اگر سرویس قیمت در دسترس نباشد، سایت با آخرین قیمت معتبر به کارش ادامه می‌دهد.

### پشتیبان‌گیری
همه‌ی اطلاعات (محصولات، سفارش‌ها، تنظیمات) در فایل `data/dornia.sqlite` و عکس‌ها در `uploads/` هستند. از این دو مرتب نسخه‌ی پشتیبان بگیرید.

## اجرا روی کامپیوتر برای تست

```bash
php -S 127.0.0.1:8000
```
سپس آدرس http://127.0.0.1:8000 را باز کنید.

## ساختار پوشه‌ها

| مسیر | توضیح |
|---|---|
| `index.php`, `shop.php`, `product.php`, ... | صفحات سایت |
| `admin/` | پنل مدیریت |
| `app/` | منطق برنامه (دیتابیس، قیمت‌گذاری، قالب) — دسترسی مستقیم بسته است |
| `assets/` | استایل، اسکریپت، فونت وزیرمتن، لوگو و آیکون‌ها |
| `data/` | دیتابیس و رسیدهای واریز — دسترسی مستقیم بسته است |
| `uploads/` | عکس محصولات |

فایل‌های لوگو: `assets/img/logo.svg` (زمینه روشن)، `logo-light.svg` (زمینه تیره)، `logo-square.svg` (پروفایل اینستاگرام).
