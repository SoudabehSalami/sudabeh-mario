نصب داشبورد بانک‌ها روی ویندوز

این نسخه داخل حساب گوگل خودتان اجرا می‌شود و برای دیدنش به Claude نیازی نیست. حدود ۵ دقیقه طول می‌کشد. مرحله‌ها را به ترتیب انجام دهید.

1

پروژه بسازید

  1. script.google.com را باز کنید و New project را بزنید.
  2. بالای صفحه روی Untitled project بزنید و اسمش را «داشبورد بانک‌ها» بگذارید.
2

کد اصلی را بگذارید

فایل Code.gs را باز کنید، هرچه داخلش هست پاک کنید و این را جایش بچسبانید:

Code.gs
3

فایل صفحه را اضافه کنید

کنار Files روی + بزنید، HTML را انتخاب کنید و اسمش را دقیقاً Index بگذارید. محتوای پیش‌فرض را پاک کنید و این را بچسبانید:

Index.html
4

تنظیمات پروژه را بگذارید

از منوی چپ Project Settings (چرخ‌دنده) را باز کنید و تیک Show "appsscript.json" manifest file in editor را بزنید. بعد به Editor برگردید، فایل appsscript.json را باز کنید و محتوایش را با این عوض کنید:

appsscript.json

در آخر با Ctrl+S همه را ذخیره کنید.

5

منتشر کنید

  1. بالا سمت راست Deploy و بعد New deployment را بزنید.
  2. روی چرخ‌دندهٔ کنار Select type بزنید و Web app را انتخاب کنید.
  3. Execute as را روی Me و Who has access را روی Only myself بگذارید. اگر همکاران باگلوس هم باید ببینند، گزینهٔ دامنهٔ باگلوس را انتخاب کنید.
  4. Deploy و بعد Authorize access را بزنید و حساب گوگلتان را انتخاب کنید. اگر پیام «Google hasn't verified this app» آمد، Advanced و بعد Go to داشبورد بانک‌ها را بزنید و در آخر Allow. این اسکریپت مال خودتان است و فقط اجازهٔ خواندن شیت‌ها را می‌خواهد.
  5. لینک Web app را کپی کنید. با script.google.com/macros/s/…/exec شروع می‌شود.
6

روی ویندوز نصب کنید

  • Chrome: لینک را باز کنید، منوی ⋮ را بزنید و Cast, save and share و بعد Install page as app را انتخاب کنید.
  • Edge: لینک را باز کنید، منوی … را بزنید و Apps و بعد Install this site as an app را انتخاب کنید.

از این به بعد داشبورد در منوی Start و روی دسکتاپ هست و در یک پنجرهٔ جدا باز می‌شود. هر بار که بازش کنید، از گوگل‌شیت خوانده می‌شود و تا وقتی باز است هر ۱۰ دقیقه خودش به‌روز می‌شود.
